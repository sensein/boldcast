# `data/` — open-access inputs only

**No DUA-bound file may live in this directory, or anywhere else inside
this repo.** The whole tree gets cloned, rsynced, tarred, and copied
between clusters; anything sitting here travels with it.

What belongs here: open-access artifacts that are merely inconvenient to
regenerate. Currently `atlases/` (Schaefer 2018 fsLR-32k parcellation).
The contents are gitignored — only this file is tracked.

## Where the DUA-bound files live instead

| File | Location | Referenced via |
|------|----------|----------------|
| HCP Restricted family-ID table | outside the repo, mode `600` under a `700` directory | `$HCP_RESTRICTED_CSV` in `.env` |
| HCP S1200 imaging data | on the ORCD data filesystem | `$HCP_ROOT` in `.env` |

Both are consumed through environment variables set in the gitignored
`.env` (loaded by `boldcast.utils.env.load_repo_dotenv`), never through a
path inside the repo. `scripts/build_family_disjoint_splits.py` already
defaults `--restricted-csv` to `$HCP_RESTRICTED_CSV`.

Real HCP subject IDs are DUA-bound too, which is why `configs/subjects_*.txt`
are gitignored and regenerated by `scripts/build_subject_lists.py` and
`scripts/build_family_disjoint_splits.py` rather than committed.
